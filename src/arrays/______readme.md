DON'T ASK:
"What is the algorithm?"

ASK:

1. What decisions do I have?

2. What is the state after a decision?

3. What makes a state invalid?

4. Can I forget the exact history?

5. What is the minimum information
   I need to carry forward?

6. Can multiple possibilities be
   represented as one state/range?

7. What happens to that state when
   I process the next element?
